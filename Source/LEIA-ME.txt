T-TEA — Versão compilada para Windows (64 bits)
=================================================

COMO EXECUTAR
  1. Copie a pasta inteira "T-TEA" para o computador (ex.: C:\T-TEA).
  2. Dê dois cliques em T-TEA.exe. Não é preciso instalar Python nem bibliotecas.

REQUISITOS DO COMPUTADOR
  - Windows 64 bits (x64). NÃO funciona em Windows 32 bits — o MediaPipe
    (detecção de pose do Google) nunca foi disponibilizado para 32 bits.
  - Windows 10 e 11: funciona diretamente.
  - Windows 7: precisa ser 64 bits com Service Pack 1 e a atualização
    KB2533623 instalada (Windows 7 atualizado via Windows Update já a possui).
  - Webcam conectada antes de abrir o programa.

CÂMERA
  - Clique na engrenagem (⚙) no canto superior direito do menu para escolher
    qual webcam usar. A escolha vale para todos os jogos e para a calibração,
    e fica salva em "config.json".

REGISTROS (LOGS)
  - log.txt   : mensagens dos jogos (jogador, fase, nível, calibração).
  - debug.txt : tudo do log.txt + erros e diagnóstico. Se algo não funcionar,
    envie este arquivo para a equipe do projeto.
  - Os dois arquivos nunca passam de 2 MB (as linhas antigas são apagadas).

DADOS
  - Os cadastros e sessões dos jogadores ficam na pasta "Jogadores".
  - A calibração fica em "calibracao.csv".
  - Para preservar os dados ao atualizar o programa, copie a pasta "Jogadores"
    e o arquivo "calibracao.csv" para a versão nova.

Se o Windows SmartScreen bloquear a execução ("Windows protegeu o seu
computador"), clique em "Mais informações" > "Executar assim mesmo".
