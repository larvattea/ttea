T-TEA — Windows build (64-bit)
================================

QUICK START
  1. Copy the whole "T-TEA" folder to the computer (example: C:\T-TEA).
  2. Double-click T-TEA.exe.
  3. That's it. No Python install, no extra setup.

BEFORE YOU OPEN IT
  - Plug in the webcam FIRST, then open the app.
  - Needs 64-bit Windows. 32-bit will NOT work (pose detection has no
    32-bit version, period — not fixable).
  - Windows 10 / 11: just works.
  - Windows 7: needs SP1 + update KB2533623. Windows Update usually already
    has it installed.

SETTINGS (gear icon ⚙, top right of the menu)
  - Pick your webcam. You'll see a live preview with the skeleton overlay,
    so you know it's the right camera.
  - Pick which monitor the games go fullscreen on.
  - Both choices apply to every game and are remembered (saved to
    config.json) — you only set them once.

CALIBRATION (main menu, two buttons)
  - "Calibrar Manualmente" — click the 4 corners yourself.
  - "Calibrar Automaticamente" — projects a checkerboard pattern and
    calibrates on its own. Faster, less room for error.
  - The camera preview window always opens on the OTHER monitor from the
    game, so it doesn't sit on top of the projection.

HOW TO QUIT
  - Press Q. Works in every game (KarTEA, RepeTEA, VesTEA). Takes you
    straight back to the menu.

IF SOMETHING BREAKS
  - Check debug.txt first — it logs errors automatically.
  - Send debug.txt to the project team, they'll know what happened.
  - log.txt is the lighter version (just player/phase/level/calibration
    info, no error noise).
  - Both files auto-trim at 2 MB, so they never get huge.

YOUR DATA — DON'T LOSE IT
  - Player accounts + session history: "Jogadores" folder.
  - Calibration: "calibracao.csv".
  - Updating to a new version? Copy those two things over BEFORE you
    replace the folder. Otherwise you lose them.

WINDOWS BLOCKS THE APP?
  - You'll see "Windows protected your PC".
  - Click "More info" → "Run anyway".
  - This is normal for unsigned apps, not a virus warning.
